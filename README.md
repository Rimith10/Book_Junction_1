# 📚 Book Junction – Online Bookstore Website

**Book Junction** is a beginner-level web development project that demonstrates the design and structure of an online bookstore website. The project aims to provide a simple, user-friendly interface where visitors can explore books and navigate through different sections of a bookstore.

The website is being developed as part of my learning journey in web development, helping me understand how multiple HTML pages are structured, linked, and presented as a single website.



## 🎯 Project Objective

The main objective of Book Junction is to build the front-end structure of an online bookstore and gain practical experience in creating web pages, organizing website content, linking pages, and improving the overall user interface.



## ✨ Features and Sections

The website includes the following sections:

- **Home:** Introduces the website and provides the main navigation experience.
- **Books:** A dedicated section for displaying book-related content.
- **Categories:** Organises books into categories to make browsing easier.
- **Search:** Provides a search interface for exploring books.
- **Cart:** A page designed for the shopping cart section.
- **Login:** A page designed for the user login interface.
- **About:** Provides information about the website.
- **Contact:** A section for contact-related information.



## 🛠️ Technologies Used

### 1. HTML5
Used to create the structure of the website, including headings, navigation links, sections, forms, and other page elements.

### 2. CSS
Used to style the website, including colours, layouts, spacing, typography, and other visual elements, wherever styling has been implemented.

### 3. Git and GitHub
Used for version control and repository management, making it easier to organise, track, and share the project.

### 4. Visual Studio Code / VS Code
Used as the code editor for developing and managing the website files.

**Status: -Front-End Prototype / Work in Progress**
          -Book Junction currently focuses on the website's structure, page navigation, and visual presentation.
          -The website is not yet a fully functional e-commerce platform. Some sections may currently serve as interface demonstrations rather than complete working features.

The following improvements are possible future additions:

- Implementing functional book search and category filtering.
- Adding JavaScript for interactive elements.
- Implementing cart operations such as adding, removing, and updating books.
- Developing user registration and login functionality.
- Connecting a backend to manage users, books, and orders.
- Integrating a database for persistent storage.
- Adding payment integration and order management.
- Improving responsive design for mobile phones, tablets, and desktops.
- Integrating AI to help customers choose their books based on their interest.
